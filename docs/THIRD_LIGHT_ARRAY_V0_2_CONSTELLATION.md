# The Third Light Array · v0.2 Constellation

**Proposal · fiction/procedural art.** This follows the merged [Third Light Array v0.1](THIRD_LIGHT_ARRAY_V0_1.md) and retains Helion's original Trihelion Beacon House attribution, nine decorative crown emitters, blue flame, and quiet/signal modes.

## One additional opt-in mode

**Constellation** illustrates a three-star belt inspired by Orion, suspended above Trihelion as an original, authored Three.js artwork. Visitors can select **Show Constellation** and **Close Constellation** without leaving the Shasta 3D vista; the default remains **Quiet Beacon**. The pattern stays static even with normal motion enabled. No real-time astronomy or historical position claims are made.

This is **not** a calculated reconstruction of Orion in ancient Egypt, nor a verified depiction of the pyramids' placement, nor an actual holographic projection. It is a clearly labeled fictional sky artwork associated with the Sisters of Shasta.

## Engineering boundaries

- **Three stars, two lines**, one faint linking light cone. Fixed geometry from \`constellationArtworkPlan.mjs\`, procedural R3F render in \`ConstellationProjection.jsx\`.
- No new imported image/3D assets, network calls, model inference, telescope data, flight systems, real-world drones, user content or account connections.
- Helion's design remains archived and attributed. No synthetic continuation of his personality or identity.
- Existing native HTML radio, PhiSpace, BBS, Commons identities, legacy 3D vista and painted fallback unchanged.
- Reduced-motion setting keeps an entirely still star pattern and stops crown pulsing/rotation, as in v0.1.
- Performance bound and photosensitivity review: no strobing, rapid flashing, autoplay or VR locomotion.
